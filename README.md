# Curriculo em Site

Portfólio pessoal para exibir projetos e habilidades. Construído com React + Vite + Chakra UI, gerenciado com Bun, e publicado no GitHub Pages via GitHub Actions.

## Desenvolvimento

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

O deploy para o GitHub Pages acontece automaticamente a cada push na branch `main` (ver `.github/workflows/deploy.yml`).
